# 正文页与项目详情页排版

> 列表页（文章列表、项目网格）已在 `01-design-spec.md` §4.5.2 / §4.5.3 定稿；本文档补齐**点进去之后**的两页。
> 继承既有语言：纯黑底、单色细线、等宽微标签、无框无卡片、两头渐隐的分隔线。

---

## 1. 文章正文页（`/blog/[slug]`）

**核心取舍：阅读页不放动效背景。** 首页/列表页的实时模拟是"门面"，正文页的第一任务是读字——所以正文页**纯黑底、无画布**，只保留顶栏、顶部滚动进度线和页脚。这同时省掉一次 WebGL/Canvas 初始化，是性能上最划算的决定。

### 版式

| 元素 | 规范 |
| --- | --- |
| 容器 | 单列，正文 `68ch` 居中；页面两侧留白 ≥ 32px |
| 页头 | 等宽 kicker（`2026-09-18 · 8 MIN · RUST`）→ `h1`（clamp 28–40px）→ 一句话简介（正文灰，最大 46ch）；下方一条**两头渐隐**的 1px 线收口 |
| 正文 | 16px / 行高 1.8；中文用系统字体栈，代码与数字用等宽 |
| 层级 | `h2` 22px / `h3` 18px，均带 0.5 倍上间距；正文段落间距 1.2em |
| 链接 | 下划线（1px，透明度 0.35），悬停时下划线变亮；站外链接带 `↗` 小标记 |
| 引用 | 左侧 1px 竖线（两头渐隐），无背景色、无斜体 |
| 分隔 | `---` 渲染成一条两头渐隐的 1px 线 |
| 行内代码 | 等宽 0.92em + 极淡底色（`rgba(255,255,255,.06)`），无圆角 |
| 代码块 | **彩色语法高亮**（已确认，主题需与纯黑底相配：关键字/字符串/数字/注释四色，饱和度压低，不使用大面积底色）。黑色面板 1px 描边、无圆角、无行号；语言标签以等宽小字置于左上；右上角复制按钮（点击后短暂显示 `COPIED`）；超宽横向滚动，不换行 |
| 图片 | 全宽（可超出正文到容器宽度），1px 描边、无圆角；下方一行等宽小字作为说明；**点击打开全屏灯箱**；必须写 alt |
| 表格 | 仅有横向发丝线，无竖线、无斑马纹；数字右对齐并等宽 |

### 三个附属件

1. **目录（TOC）**：桌面端粘在右侧（宽度 ~200px），列出 `h2`/`h3`；当前所在小节高亮。**< 1100px 时收起**为正文顶部的一个可展开列表，不隐藏功能。
2. **阅读进度**：复用已有的顶部 1px 进度线（与首页同一套实现），不新增元素。
3. **文末**：标签（可点，跳到对应筛选）→ 更新时间 → 上一篇 / 下一篇（仅标题，两头渐隐线分隔）→ **评论区（giscus，滚动到此处才加载）**。

### 灯箱（已确认使用）

- 点击正文插图或项目图集任意一张 → 打开**全屏黑底灯箱**：图片居中、上下留白，左右方向键切换同组图片，`Esc` 或点击空白处关闭。
- 实现**不引第三方库**：一段约 2–3 KB 的原生脚本（`<dialog>` 或一个遮罩层），只在页面确实含图片时初始化。
- 无障碍：聚焦进入灯箱、关闭后焦点回到原图；左右切换有 `aria-live` 提示；`prefers-reduced-motion` 下不做缩放过渡。
- 关闭时**不改变页面滚动位置**（记住打开前的 `scrollY` 并还原）。

## 2. 项目详情页（`/projects/[slug]`）

**与正文页的区别**：项目页是"展示"，允许图片更多、有外链面板，因此用**两栏**；同时它与项目列表共用视觉语言（左侧竖线标记）。

| 元素 | 规范 |
| --- | --- |
| 版式 | 桌面两栏：**左侧信息栏 240px（sticky）** + 右侧内容区；< 900px 折成上下 |
| 左栏 · 信息 | 一句话简介 → 等宽清单：`年份` / `技术栈`（每项一行）→ 链接列表（`REPO` / `VIDEO` / `DEMO` + 外链，统一 `target="_blank" rel="noopener noreferrer"`） |
| 右栏 · 内容 | 封面图（全宽）→ 正文（Markdown，排版规则同文章正文）→ 图集 |
| 图集 | 1–2 列网格，图片等宽、等高裁切；**点击打开全屏灯箱**（与正文页同一套实现，同组内可左右切换） |
| 左栏样式 | 与项目卡片一致：左侧一条**两头渐隐的 1px 竖线**，上方等宽编号/年份 |
| 背景 | 与所在页面一致：**纯黑、无画布**（与正文页同理，展示靠图与文字） |
| 文末 | 技术栈标签 → 返回项目列表 → **评论区（giscus，与文章页同一套，滚动到此处才加载）** |

---

## 3. 两页共用的规矩

1. **无卡片、无圆角、无彩色**：所有分隔只靠 1px 线与间距。
2. **外链一律新标签打开**并带 `rel="noopener noreferrer"`。
3. **图片一律构建期优化**为 AVIF/WebP 多尺寸，显式写 `width/height` 防抖动，首屏之外的图 `loading="lazy"`。
4. **代码高亮在构建期完成**（Shiki），首屏零成本。
5. **两页都不放动效背景**，这是性能与可读性的共同选择；若以后想加，只允许"极低亮度的静态纹理"，不允许实时模拟。
