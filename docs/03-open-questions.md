## B 组 · 视觉与交互（⭐ 必须确认）

| B2 ✅ | 参考已收到：**vercel.com 风格截图**（纯黑 + 巨型居中标题）｜**jiejoe.com/home**｜**wodniack.dev**｜**cosmicbroth.com** | 已记录在 `01-design-spec.md` §4.5.1 的"借鉴 / 不借鉴"清单 | 后续视觉工作以此为准 |
| B3 ✅ | 动效组合 —— **已确定**：**首屏背景 = 混沌三体运动**（发光光源点 + 短拖尾、不抢戏），**首屏右侧 = 三维轨道球原子**，页面之间用**整屏发丝线扫过**的切换动效过渡 | 已锁定，原型即为最终形态 | 已收敛 |

| B4 ⭐ | 是否需要唯一的强调色？还是全站只用黑/白/灰三档？ | **只用黑/白/灰**，把强调色完全去掉，最纯粹也最耐看 | 决定链接、当前项、光标等交互点的处理方式 |
| B5 | 线条的"运动气质"偏好？（慢而稳定 / 有呼吸感 / 有明确节奏 / 接近机械） | 慢而稳定、几乎察觉不到在动 | 影响动画周期、速度与幅度 |
| B6 | 动画在页面中的角色？（只在首屏 / 全站常驻 / 只在特定交互时出现） | 只在首屏 Hero；其余页面留白与排版为主 | 决定性能预算的分配 | 
| B7 | 字体偏好？是否接受"中文用系统字体、拉丁用自托管等宽字体"？ | 接受（这是轻量化的关键） | 若坚持自托管中文字体，首屏将增加数 MB |
| B8 | 纯黑为主，还是也需要亮色主题？ | 纯黑为主 + 提供纯白亮色主题（线条转黑） | 双主题增加一轮对比度校准工作 |
| B9 | 是否接受音效（默认关闭，用户手动开启）？ | 首版不做，作为彩蛋预留 | 涉及浏览器自动播放策略 |
| B10 | 是否接受页面切换过渡、滚动触发的线条变化？ | 接受（线条变化优先用透明度与位置，不用缩放） | 影响"极简"的纯净度 |
| B11 | 移动端降级容忍度？ | 移动端降低线数与帧率，极端情况用静态帧 | 影响真机流畅度与电量 |
| B12 | 首页第一句话（Hero 文案）想写什么？ | 待你给出，或先用"<身份> · <关注领域>"格式占位 | 首屏最重要的一句话 |
| B13 | 鼠标交互还要不要？当前只保留约 1–2% 的视差（制图十字、指针连线、波动线隆起均已按你的要求删除）。可选：完全取消 / 保持视差 / 指针靠近时轻微加快天体运动（不新增画面元素） | 保持当前视差 | 影响"炫技"与"干净"的平衡 |
