# 0008 · P1 的视觉默认值与待办取舍

状态：已采纳（2026-09-30，P1）

## 背景

`03-open-questions.md` 的 B 组视觉条目里只有 B1–B3 由用户确认过，其余都带"推荐默认值"。
P1 落地设计系统时必须把这些默认值变成真实取值，并说清楚哪几条会在后面被推翻。

## 决策

1. **强调色（B4，⭐）**：采用推荐默认值"**只用黑 / 白 / 灰**"。
   `--color-accent` 在深色下就是近白 `rgba(255,255,255,.86)`、亮色下是近黑，
   本质上没有引入第二种色相。日后若想要一个强调色，只改这一个令牌即可全站生效。
2. **弱化层级 `--color-fg-3` 的对比度** —— **已于 P4 修正**。
   最初取 0.38（深色约 3.4:1、亮色约 3.0:1），低于小字号 4.5:1 的 AA 线，
   当时把它当作"有意退到背景里的层次"。P4 上线后质量门禁里的 Lighthouse
   可访问性（内部就是 axe 的 `color-contrast`）稳定判红，而这一档用在
   kicker、日期、标签、页脚链接、搜索框占位符上，影响面很大。
   现在改为 **深色 0.48（4.92:1）、亮色 0.56（4.94:1）**：达标，且仍明显弱于
   `fg-2`（6.5:1）—— 层级关系保留，只是不再低于 AA。
3. **导航与站内链接暂时会进 404**：顶栏按信息架构（§2.1）已经指向
   `/blog`、`/projects`、`/about`，但这些页面 P2 才创建。
   P1→P2 之间点它们会落到 404 页，这是施工顺序，不是缺陷。
4. **首页 Hero 只有文字**：招牌视觉（三体背景、滚动特效、页面切换）属于 P3，
   所以首页暂时没有按钮、没有画布。`Button` 组件目前只被 404 页使用；
   `Card` 组件已就位但**禁止**用于文章列表与项目网格（规范要求"无卡片、无边框"）。
5. **字体分工**：Hero 标题走 `--font-sans`（中文系统栈），等宽字体只用于微标签与代码。
   若希望站点名用等宽字，把首页 `<h1>` 的 `font-sans` 换成 `font-mono` 即可（一行）。

## 影响

- P3 落地招牌视觉时，Hero 的**文字结构可以原样保留**，只在外层叠加画布与动效。
- P4 做质量门禁时，第 2、3 条是已知且可解释的项目，避免被误判成回归。
