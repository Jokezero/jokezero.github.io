## 打开方式

用浏览器直接打开，或双击文件。**注意**：文件是本地页面，浏览器不会在你改完文件后自动重新加载——每次拿到新版本都需要**强制刷新**（`Ctrl/Cmd + Shift + R`）。

## 怎么确认看到的是最新版

页脚右下角有版本戳（例如 `REV 25 · 2026-09-29`）。核对版本号即可，不用靠肉眼猜。

## 这份原型的边界

它是**设计参照物，不是最终实现**：

- 所有样式与脚本都写在一个 HTML 文件里，便于讨论，不适合直接上线。
- 实现时按 `../01-design-spec.md` 重写为 Astro 组件；`../01-design-spec.md` §4.5.4 里明确标注的"遗留规则"不要移植。
- 原型里的文案、项目、文章均为占位内容。
